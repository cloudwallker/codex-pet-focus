# Codex Pet Focus 实施计划

用户已批准 2026-09-15 对话中的完整方案；以下保存执行约束。

## 全局约束

C#/.NET 10/WPF/Win32，Windows 本地助手＋.codex-plugin/plugin.json 技能入口。只增强原桌宠。运行不调用模型、不联网；不开 MCP、聊天轮询或定时模型任务。数据存 %LOCALAPPDATA%/CodexPetFocus，版本化 JSON、原子写、备份，计时每5秒检查点。

## Task 1：接入验证

可靠定位原宠物 HWND、精灵边界；先做可恢复短距离移动实验，再针对渲染窗口投递 WM_MOUSEMOVE/WM_MOUSELEAVE。必须观察自带 jumping 完整播放、可重复、能退出；真实鼠标、前台窗口、系统最后输入时间不被改变。没有真实验证通过就不实现完整自动动作；禁止整窗弹跳、移动真实光标、注入或修改客户端。失败报告保留，独立任务功能继续实现。

## Task 2：任务与存储

多行今日计划一行一个任务。每任务启动/停止/完成，单运行任务，切换自动暂停。单调时钟累计，停止再启动继续；普通空闲继续，锁屏/睡眠/退出暂停，恢复手动继续。午夜按本地日期拆分；崩溃恢复最近5秒检查点且暂停。完成统计、今日用时、昨日未完成一键转入并去重。版本化JSON原子保存、上一份备份；不能静默覆盖损坏数据。

## Task 3：本地界面和插件

WPF任务面板、透明非激活头顶横幅、托盘、设置。横幅仅运行时显示“任务名称 · HH:MM:SS”，每秒刷新。勿扰停自动动作而不停止计时；一键归位。默认关闭开机启动，可设置开启。技能仅安装、启动、诊断。安装/卸载保留任务数据。构建、测试、打包、兼容性说明。

## Task 4：完整自动动作（受 Task 1 硬门槛约束）

10分钟会话键鼠无输入后保存位置，移至宠物所在显示器中心并将浮窗/横幅限制在同屏可用区，每5秒触发一组原生jumping。真实鼠标或键盘恢复则退出模拟hover并快速回原位。手动拖动更新下次原位。DPI、负坐标、屏幕拔插、隐藏重开、减少动态效果需覆盖；升级适配不明时禁用控制。未通过 Task 1 则本任务不实现并明确未完成原因。

## 验收

断网任务闭环；启停切换、跨日、系统时间改变、锁屏睡眠、崩溃及备份恢复；原宠物定位/动作/横幅不抢焦点；多屏缩放/负坐标/屏幕拔插；原生动画真实观察；发布包启动与技能验证。每个子任务均需测试与独立代码审查。
