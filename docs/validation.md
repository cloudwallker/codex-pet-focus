## 应用验收

已使用发布程序和项目内隔离数据目录，通过真实 Windows UI Automation 完成：

- 多行录入三项中文计划；启动、停止、继续及切换任务，只有一项运行。
- 标准 TogglePattern 完成正在运行的任务，完成数更新、计时暂停、横幅隐藏。
- 勿扰设置落盘，任务计时和横幅继续。
- 关闭面板后再启动，同一数据目录的第二实例退出并唤醒原实例。
- 强制结束隔离进程后重启：原检查点保持、所有任务暂停。本次检查点距退出 0.773 秒。
- 锁定测试数据文件模拟写入失败：出现持久错误、计时暂停、旧文件字节保持不变。
- 诊断命令正常退出、返回真实 UIA 定位及禁用动作状态；任务文件哈希不变。
- 实际横幅窗口样式为 `0x80800a8`，含 NOACTIVATE、TRANSPARENT、LAYERED；前台窗口保持任务面板，未转到横幅。
- 原宠物在副屏负坐标处，UIA 精灵位置变化后，横幅跟随新的边界。未向原宠物发送移动或动画消息。
- 已查看任务面板及原宠物横幅截图。开发记录：`artifacts/ui-qa/panel.png`、`banner-pet.png`。

插件 ZIP 中已核实清单、可执行程序和技能均存在。运行源码未发现网络客户端、模型调用或原宠物输入控制调用；测试进程未观察到 TCP 连接。

以下场景不能以逻辑测试代替真实环境通过记录：其他缩放比例、拔屏、更换主屏、其他宠物、真实锁屏睡眠与系统减少动态效果。当前自动动作未开放，因此未宣称满足完整动作验收。

代码无网络或模型调用。未为验证而断开用户电脑的网络连接。
